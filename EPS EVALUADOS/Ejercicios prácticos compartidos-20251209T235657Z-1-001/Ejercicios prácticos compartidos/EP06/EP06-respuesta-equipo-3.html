Un equipo de investigadores del área de interacción humano-información está estudiando si el área temática y el nivel de dificultad del problema de información influyen en el tiempo (en segundos) que toma un usuario en formular una consulta de búsqueda para resolver dicho problema. Para ello, han reclutado a un grupo de participantes voluntarios, asignados aleatoriamente a distintos grupos. Cada participante debe resolver tres problemas de información con diferentes niveles de dificultad: baja, media y alta. A su vez, cada grupo debe resolver problemas relacionados a una temática diferente.

Equipo 3: En este momento, los investigadores buscan determinar si existen diferencias en el tiempo que tardan los usuarios en formular consultas para problemas con diferente nivel de dificultad en el área de química.

data = read.csv("EP06 Datos.csv")
#Formato largo
largeData = data %>% filter(area == "Química")
#Reiniciamos id para poder utilizar ezANOVA
largeData <- largeData |>
  group_by(id) |>
  mutate(id = cur_group_id() - 1) |>
  ungroup() |>
  mutate(id = factor(id),dificultad = factor(dificultad))
#Formato ancho
wideData = largeData %>% pivot_wider(names_from = dificultad, values_from = tiempo)
wideData = wideData %>% select(-area)

Teniendo ya los datos filtrados interesados y en formato ancho.

Para la responder la pregunta enunciada, en un contexto de medidas repetidas, se propone las siguientes hipotesis; como hipotesis nula se tiene que el tiempo promedio que tardan los usuarios en formular consultas, es el mismo para todos los niveles de dificultad en el area de quimica; como hipotesis alternativa se tiene que el tiempo promedio que tardan los usuarios en formular consultas, es diferente en al menos un nivel de dificultad en el area de quimica. Sea \(t_a\) la dificultad alta, \(t_m\) la dificultad media y \(t_b\) la dificultad baja

\[ H_0: \mu_{t_b-t_m} = \mu_{t_b-t_a} = \mu_{t_m-t_a} = 0 \\ H_a: \exists X,Y \in \{b,m,a\},X \neq Y \mid \mu_{t_X-t_Y} \neq 0\]

Dada las hipótesis, un test de ANOVA de una vía con muestras correlacionadas es adecuada, siempre que se tengan las condiciones necesarias para realizarla, se realizara con un grado de significancia del 0.05. La primera condición se cumple al tener como variable dependiente el tiempo, cumple con escala de intervalos iguales; la segunda condición de muestras independientes, se cumple al señalar en el enunciado que se asignaron personas aleatoreamente a los grupos, a su vez que las personas seleccionadas en el área de Química es menos del 10% población (siendo 200 personas).

Para la tercera condición, se realizaran tests de normalizacion para cada dificultad.

Dados los tests de Shapiro-Wilk, las diferentes muestras fallan en rechazar la hipótesis nula de provenir de una población no parametrica con un intervalo de confianza del 95%, por lo que se cumple la tercera condición de normalidad.

La cuarta condición corresponde a que las diferencias de las varianzas de las diferentes dificultades, sean todos iguales. Afortunadamente el test ezANOVA, nos va a verificar esta condición.

res = ezANOVA(data = largeData, dv = tiempo, wid = id, within = dificultad)
pruebaAov = aov(tiempo ~ dificultad + Error(id/dificultad), data=largeData)

El resultado presentado por el test de ANOVA de una vía para varias muestra; nos muestra que el tamaño del efecto es de 0.064888 siendo >0.06, según criterio de Cohen, un tamaño de efecto mediano, donde el 0.06488% de la variación del tiempo se debe a la dificultad; mientras el p-value entregado por el test es de \(7.38340*10^{-9}\) siendo menor a nuestro grado de significancia 0.05, tenemos suficiente evidencia estadistica para rechazar la hipótesis nula en favor de la hipótesis alternativa. Dado que en nuestro contexto, el test de ANOVA para varias muestras es una prueba ómnibus, hay que realizar una prueba post-hoc para determinar que diferencias de medias de tiempos entre las muestras tienen diferencias.

Usando los tests post-hoc de Benjamini y Hochberg.

Dado el resultado de los tests post-hoc y el grafico, indica que el tiempo promedio requerido de una persona para formular consultas, es menor en la dificultad baja, mientras que en dificultad media y alta, el tiempo promedio requerido es mayor. De los test se rescata que el p-value de alta-media, es de 0.67, lo cual es mayor a nuestro grado de insignificancia, lo que quiere decir por t-test que no hay suficiente evidencia estadística para afirmar que sus medias son diferentes. Mientras que para alta-baja y media-baja, se tiene suficiente evidencia estadística para afirmar que los promedios son diferentes entre estos.
