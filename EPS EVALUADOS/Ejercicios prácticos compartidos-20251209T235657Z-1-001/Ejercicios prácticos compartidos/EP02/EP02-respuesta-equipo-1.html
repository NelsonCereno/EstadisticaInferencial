El Comité Olímpico cree que el mejor tiempo medio de los atletas de la zona Sur después de ingresar al programa de entrenamiento es superior a 12,4 segundos. ¿Soportan los datos esta afirmación?

# Primero obtenemos los datos de la zona Sur
zonaSur <- datos[datos$Zona == "Sur",]

x <- summary(zonaSur)
x

##  1st Qu.:17.75   Class :character   1st Qu.:13.23   1st Qu.:11.82

##  3rd Qu.:58.25                      3rd Qu.:14.84   3rd Qu.:13.09

Por el enunciado sabemos que los datos son independientes. Y por la funcion summary se puede apreciar que los datos son < 30, 28 para ser exactos.

Ahora se analiza la normalidad de los datos:

prueba <- shapiro.test(zonaSur$Posterior)
prueba
## 
##  Shapiro-Wilk normality test
## 
## data:  zonaSur$Posterior
## W = 0.95201, p-value = 0.2225
ggqqplot(zonaSur, x="Posterior")

Dado que p = 0.2225 se puede aceptar que los datos son normales

Dada estas condiciones se puede aplica una prueba t con un 95% de confianza Donde:

  • \(H_O\): media posterior = 12,4
  • \(H_A\): media posterior > 12,4
## definimos el nivel de confianza
alpha <- 0.05

t.test(zonaSur$Posterior, mu = 12.4, conf.level = 1 - alpha, alternative = "greater")
## 
##  One Sample t-test
## 
## data:  zonaSur$Posterior
## t = 0.62078, df = 27, p-value = 0.27
## alternative hypothesis: true mean is greater than 12.4
## 95 percent confidence interval:
##  12.14311      Inf
## sample estimates:
## mean of x 
##  12.54732

Como se obtiene un valor p mayor que \(\alpha\), quiere decir que no hay evidencia suficiente para rechazar la hipotesis nula, por lo que podemos decir con un 95% de confianza que la media posterior al entrenamiento de los atletas de la zona sur es igual a 12 segundos.
